# WRAITH

A Cybersecurity Escape-Room Game

Wraith is an interactive web-based game where players investigate suspicious activity, solve cryptography puzzles, detect phishing attempts, and uncover clues through cybersecurity missions.

## Features
- Digital Detective investigations
- Phishing detection challenges
- Interactive evidence board
- Cryptography puzzles
- Mission-based gameplay

## Technologies
- HTML
- CSS
- JavaScript

## Team
Developed collaboratively as a student project.
